# Orbit

> An AI-powered browser automation engine.

Orbit is an experimental browser automation platform that converts natural language instructions into browser actions.

Instead of relying on website-specific APIs, Orbit interacts with websites through a real browser, enabling users to automate tasks using simple language.

---

## Overview

Orbit is designed to explore how AI agents can understand user intent, plan browser actions, and execute multi-step workflows.

The project focuses on browser automation, AI-assisted task execution, and modern backend architecture.
